Privacy Policy — WHOOP MCP (Personal)

Last updated: 16 September 2026

1. Overview

This privacy policy describes how a private, self-hosted software integration (the “Application”) accesses and handles data from the WHOOP API. The Application is a personal, non-commercial tool operated by a single individual for their own use. It is not offered to, or used by, any other person.

Operator / data controller: Jan Willem den Hollander
Contact: jwdenhollander@gmail.com
Location: The Netherlands (EU)

2. What the Application does

The Application runs locally on the operator's own device. It connects the operator's personal WHOOP account to a locally running assistant via the Model Context Protocol (MCP), so the operator can query and analyse their own health and fitness data. There is no server, hosted service, or shared infrastructure that other users interact with.

3. Data accessed

With the operator's explicit authorisation (via WHOOP OAuth 2.0), the Application may read the following categories of the operator's own WHOOP data:

  • Profile information (name, email associated with the WHOOP account)
  • Body measurements (height, weight, max heart rate)
  • Recovery data (recovery score, HRV, resting heart rate, and related metrics)
  • Physiological cycles (strain and heart-rate metrics)
  • Sleep data (duration, stages, efficiency, performance)
  • Workout data (strain, heart-rate zones, duration, and related metrics)

The Application only accesses the data of the account holder who authorises it.

4. How data is used

Data is used solely to let the operator view and analyse their own health and fitness information locally. Data is not used for advertising, profiling of others, marketing, or any commercial purpose.

5. Storage and security

  • All data and OAuth tokens are stored locally on the operator's own device.
  • Communication with the WHOOP API takes place over encrypted HTTPS connections.
  • No data is transmitted to, or hosted on, any external server operated by the Application.

6. Data sharing

No data is shared with any third party. The Application does not sell, transfer, or disclose WHOOP data to anyone. Data remains on the operator's device and is only exchanged directly between that device and WHOOP's own API.

7. Data retention and revocation

Locally stored data is retained only for as long as the operator chooses to keep it and can be deleted at any time by removing it from the device. The operator can revoke the Application's access to their WHOOP account at any time through their WHOOP account settings or the WHOOP developer dashboard, which invalidates the associated access and refresh tokens.

8. Children

The Application is used only by its adult operator and is not directed at, or intended for, children.

9. Changes to this policy

This policy may be updated from time to time. The “last updated” date at the top of the page reflects the most recent revision.
